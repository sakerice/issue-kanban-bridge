# 検証・デモ候補

以下はデモ手順であり録画や公開ディレクトリ審査の実施結果ではありません。架空のテストIssueだけを使います。

正常系：①空のボードを開きToDoを登録、②複雑な依頼をPlanで相談し担当を表示、③Activityまたは成果物リンク付きでReviewへ、④Claude登録→Codex完了→元セッション次回入力で結果取得、⑤定期実行結果を記録しReviewを経ずDoneへ。

拒否系：①リンク無しReview、②明示的承認無しの通常Review→Done、③Claude完了をReleaseに使用/別セッションで取得。

録画は登録、カード詳細、状態変化、元セッション結果を順に示し、個人用ボードや実Issueを画面に出さないでください。
